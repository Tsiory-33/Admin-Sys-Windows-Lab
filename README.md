# Laboratoire d'Administration Système & Réseau (Windows)

Ce dépôt représente des projets personnels en administration Windows réalisés pour approfondir les connaissances de base aqcuises durant mes études.

## 🛠 Environnement Technique
* **OS :** Windows 10 Pro
* **Hardware :** Intel Core2Duo E7400, 3GB RAM (Optimisation des ressources)
* **Outils :** PowerShell ISE, Netstat, Gestionnaire de sécurité NTFS

* **Compétence :** Scripting et WMI.

### 3. Gestion de Serveur de Fichiers (NTFS)
* **Documentation :** [Consulter la procédure de configuration](./Procedure_NTFS.md)
